Windows kurulumu

  1. İndirdiğiniz win64-setup.exe dosyasına çift tıklayın.
  2. Windows koruma uyarısı gösterirse dosyayı yalnızca bu sitenin yönlendirdiği resmî GitHub sürümünden indirdiğinizi doğrulayın.
  3. Kurulum sihirbazında ilerleyin ve Başlat menüsünden uygulamayı açın.

Pardus / Linux kurulumu

.deb dosyasına çift tıklayıp yazılım yükleyicisinde Kur seçeneğini kullanın. Yönetici erişiminiz yoksa Linux taşınabilir arşivini indirip içindeki açıklamaları izleyin.

İlk açılış

  1. Okul adı, il/ilçe ve yönetici bilgilerini girin.
  2. Ders yılını ve başlangıç/bitiş tarihlerini belirleyin.
  3. Resmî ve idari tatilleri girin. Ara tatilleri iş günü hesabından çıkarmayın.
  4. Öğrenci ve personel listesini e-Okul Excel çıktısından veya panodan aktarın.
Gerçek verileri destek talebine eklemeyin

İçe aktardığınız öğrenci/personel dosyalarını, oluşturulan evrakları, uygulama yedeğini veya ekran görüntülerini e-posta ve GitHub üzerinden paylaşmayın.

Yedekleme

Ayarlar → Güvenlik ekranından şifreli .ddbak yedeği oluşturun. Yedek cihazda şifrelenir ve herhangi bir bulut hesabına otomatik gönderilmez. Disk arızasına karşı yedeği kurumunuzun onayladığı güvenli bir ortama ayrıca kopyalayın.

İndirilen dosyayı doğrulama

Sürümle birlikte yayımlanan SHA256SUMS.txt dosyasındaki değer ile indirdiğiniz dosyanın özetini karşılaştırın.

Windows PowerShell

Get-FileHash .\disiplin-defteri-<sürüm>-win64-setup.exe -Algorithm SHA256

Pardus / Linux

sha256sum -c SHA256SUMS.txt

Sık karşılaşılan sorunlar

WebView2 bulunamadı

Windows 10 kullanılan bazı bilgisayarlarda Microsoft Edge WebView2 bileşeninin kurum bilişim sorumlusu tarafından kurulması gerekebilir.

Program zaten çalışıyor

Aynı anda yalnızca bir kopya çalışır. Görev çubuğundaki açık pencereyi bulun veya bilgisayarı yeniden başlatın.

Veritabanı bozuk uyarısı

Programı kapatın ve en son sağlam şifreli yedekten dönün. Bozuk veritabanını veya yedeği destek talebine eklemeyin.

Ayrıntılı teknik kılavuz için depodaki güncel kurulum belgesine bakabilirsiniz.
